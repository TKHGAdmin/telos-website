## Bugs

### BUG-2026-06-27-1 - Product detail page renders with broken layout (thumbnails in wrong column)

- **Severity:** P1
- **Area:** `product.html`
- **Status:** new

**What's wrong**

The product detail grid is configured as 2 columns (`grid-template-columns: 1fr 1fr`) but the DOM has 3 direct children: the main image, the thumbnails strip, and the info panel. CSS grid places them in row-major order, so on desktop the layout becomes:

- Row 1, Col 1: main image
- Row 1, Col 2: thumbnails strip (this should be the info panel)
- Row 2, Col 1: info panel (title, price, add-to-cart, description)

Result: the title/price/CTA get pushed below the main image instead of sitting next to it, and the right column is taken up by the thumbnail strip alone. The page looks visibly broken on every product detail view on desktop. Mobile (<= 768px) collapses to a single column so it happens to render acceptably there.

This shipped with commit `f5cb8c4` ("feat: add image gallery with thumbnails on product page"). The thumbnails strip was added as a sibling of `.product-detail-image` instead of being nested with it.

**Where**

- `product.html:765-780` - the 3 sibling grid children
- `product.html:105-108` - the `grid-template-columns: 1fr 1fr` declaration

**How to reproduce**

1. Run `npx serve -l 3000 .` from the repo root.
2. Open `http://localhost:3000/shop` on a desktop-width browser.
3. Click any product card -> navigates to `/product?p=<handle>`.
4. Observe: thumbnails sit in the right column where title/price should be; the title and add-to-cart appear below the image on the left.

Verified against `origin/main` HEAD - the bug is live in production right now at https://www.telosathleticclub.com/product?p=<any-handle>.

**Suggested fix**

Wrap the image and thumbs in a single grid child so the 2-column grid still gets exactly 2 children:

```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-media">
    <div class="product-detail-image" id="productImage"></div>
    <div class="product-detail-thumbs" id="productThumbs"></div>
  </div>
  <div class="product-detail-info">...</div>
</div>
```

(No JS changes needed - `js/shop.js` still targets `#productImage` and `#productThumbs` by id.)
