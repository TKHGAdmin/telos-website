## [P1] Product detail page desktop layout broken by orphaned thumbnails div

- ID: 2026-07-14-001
- File: product.html:765-780
- Category: ui-layout
- Discovered via: static-read

**What's wrong**
`.product-detail.loaded` is defined as a 2-column CSS grid (`grid-template-columns: 1fr 1fr;` at product.html:107) but the parent `<div id="productDetail">` has three direct children: `.product-detail-image`, `.product-detail-thumbs`, and `.product-detail-info`. Auto-flow places the image in row 1 col 1, the thumbnails row in row 1 col 2 (alone), and pushes the entire info block (title, price, add-to-cart, description) into row 2 col 1 under the image. The intent, per the "add image gallery with thumbnails" commit (f5cb8c4), was clearly image + thumbs stacked in the left column and info in the right column.

**Impact**
Every desktop visitor to any product detail page (`/product?p=<handle>`) sees the primary purchase surface degraded: the "Add to Cart" button, price, and description sit in the left half of the page under the image, while a horizontal thumbnail strip floats alone in the right half with a large empty gap below it. On mobile the layout is unaffected because `@media (max-width: 768px)` collapses the grid to a single column. This is the checkout entry point for the shop - it directly harms conversion.

**Reproduction**
1. Deploy or serve locally (`npx serve -l 3000 .`).
2. Navigate to `/product?p=<any-handle>` at viewport >= 769px.
3. Observe: image top-left, thumbs top-right, product info bottom-left, empty bottom-right.
4. Grep confirms only one grid definition, no override: `product.html:105-108`, `product.html:767`.

**Suggested fix**
Wrap the image + thumbs in a single left-column container so the grid sees only two children. Minimal patch to product.html:765-780:

```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-media">
    <div class="product-detail-image" id="productImage"></div>
    <div class="product-detail-thumbs" id="productThumbs"></div>
  </div>
  <div class="product-detail-info">
    ...
  </div>
</div>
```

No CSS change needed - `.product-detail-media` inherits the column width; the existing `.product-detail-thumbs` `margin-top: 12px` still applies inside it.
