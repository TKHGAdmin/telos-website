## BUG-20260621-01  P1  Product detail page layout collapses on desktop after image-gallery commit

**Status:** new
**Area:** product-page
**Files:** product.html:765-779, product.html:100-115, js/shop.js:165-177

### What's broken
Commit `f5cb8c4` ("feat: add image gallery with thumbnails on product page") inserted a new `<div class="product-detail-thumbs" id="productThumbs"></div>` as a direct child of `.product-detail`, which is styled `display: grid; grid-template-columns: 1fr 1fr;` on desktop. The grid now has three siblings (image, thumbs, info) auto-placed into a 2-column grid, so:
- image lands at row 1 / col 1 (intended)
- thumbs lands at row 1 / col 2 (where the product title + price + Add-to-Cart were supposed to live)
- info wraps to row 2 / col 1 at half width, leaving row 2 / col 2 empty

This breaks every product page on viewports >768px, even for products with only one image — the empty thumbs div still claims the right column. On mobile (`max-width: 768px`) the grid collapses to one column, so vertical stacking still works there.

### Reproduction
1. Visit `/product?p=<any-handle>` on a desktop viewport (>768px).
2. Wait for the product to load (Shopify fetch completes, `.product-detail.loaded` is added).
3. Observe: the product image sits in the left column. The right column shows either an empty band or a row of thumbnails. The title, price, and Add-to-Cart button appear in the lower-left at half width.

### Expected vs actual
- Expected: two-column layout with image (with thumbnails directly below it) in the left column and title / price / Add-to-Cart / description in the right column — the layout that existed before commit `f5cb8c4`.
- Actual: title / price / Add-to-Cart pushed to a new row beneath the image; thumbnails occupy the right column where the buy panel should be.

### Suggested fix
Wrap the image and thumbs in a single grid item, e.g.:
```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-image-col">
    <div class="product-detail-image" id="productImage"></div>
    <div class="product-detail-thumbs" id="productThumbs"></div>
  </div>
  <div class="product-detail-info"> ... </div>
</div>
```
Alternatively, add `.product-detail-thumbs { grid-column: 1; grid-row: 2; }` and `.product-detail-info { grid-column: 2; grid-row: 1 / span 2; }` to keep the existing DOM. Either way, verify with a Shopify product that has multiple images so the thumbnails actually render.
