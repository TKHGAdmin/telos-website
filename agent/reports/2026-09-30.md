## P1 · Product detail page layout is broken — thumbnail `<div>` sits in the second grid column

**Bug ID:** BH-2026-09-30-001
**Severity:** P1
**Focus:** Functional
**Status:** open
**File:** `product.html:765-780`
**Related JS:** `js/shop.js:161-174`
**Introduced by:** commit `f5cb8c4` — "feat: add image gallery with thumbnails on product page" (May 20 2026)

### What breaks

`.product-detail.loaded` is `display: grid; grid-template-columns: 1fr 1fr`. Its DOM has three direct children:

```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-image" id="productImage"></div>
  <div class="product-detail-thumbs" id="productThumbs"></div>   <!-- 3rd sibling -->
  <div class="product-detail-info"> ... </div>
</div>
```

Grid auto-placement fills row-by-row, so the layout becomes:

| Row | Col 1 | Col 2 |
|---|---|---|
| 1 | product image | thumbnails (or empty stub) |
| 2 | title / price / Add-to-Cart / description | *(empty)* |

The intended two-column layout (image left, purchase panel right) is destroyed. The thumbs row was clearly meant to sit *under* the image (its CSS has `margin-top: 12px`), but it was added as a sibling of the image instead of nested inside the image column.

### Impact

- **Every product detail page** is affected — not just multi-image products. Even when the JS leaves `#productThumbs` empty (single-image product), the empty `<div>` still occupies grid row 1 col 2, so the info panel still lands in row 2 col 1.
- The "Add to Cart" button on the detail page ends up under a full-height square image on the left half of the page, with the right half blank. Conversion path is visually broken.
- Regression in the newest feature commit. Pre-May-20 the two-column layout worked.

### Reproduction

1. Deploy current `main`, or serve locally: `npx serve -l 3000 .`
2. Open `/product?p=<any-handle>` (any product loaded via Shopify Buy SDK).
3. Observe: the "Add to Cart" panel is stacked below the image on the left half of the viewport, and the right column contains only the thumbnail strip (or nothing).

### Suggested fix

Wrap the image + thumbs in one column container so the grid still sees two children:

```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-image-col">
    <div class="product-detail-image" id="productImage"></div>
    <div class="product-detail-thumbs" id="productThumbs"></div>
  </div>
  <div class="product-detail-info"> ... </div>
</div>
```

Or, if HTML structure must stay, set `.product-detail-thumbs { grid-column: 1; grid-row: 2; }` and move the info panel to `{ grid-column: 2; grid-row: 1 / span 2; }`.

### Confidence

High. Confirmed by reading `product.html` (lines 100-108 for the grid rule, lines 765-780 for the DOM) and by diffing commit `f5cb8c4` — the exact `<div class="product-detail-thumbs">` insertion is the visible cause. No JS branch avoids rendering the element, so every product hits it.
