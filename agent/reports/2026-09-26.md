## P1 — Product detail info panel is misplaced on desktop (grid layout bug)

**Location:** `product.html` lines 765–780 (DOM structure) + lines 105–108 (CSS grid). Introduced by commit `f5cb8c4` "feat: add image gallery with thumbnails on product page".

**Repro:**
1. Open any live product URL on desktop (viewport ≥ 769px), e.g. `/product?p=<any-handle>`.
2. Once the product loads, `#productDetail` gets the class `.loaded`, which sets `display: grid; grid-template-columns: 1fr 1fr;`.
3. There are **three** direct children of `.product-detail.loaded`:
   - `#productImage`   (grid cell: row 1, col 1)
   - `#productThumbs`  (grid cell: row 1, col 2) ← intended to live *under* the image, not beside it
   - `.product-detail-info`  (grid cell: row 2, col 1) ← intended to live *beside* the image, ends up below it
4. Result: the product title, price, Add-to-Cart button, and description render at half viewport width, dropped a full row below the image. The right-hand column (row 2, col 2) is empty whitespace.

**Impact:**
- Every product detail page on desktop shows a broken layout: the primary purchase CTA (Add-to-Cart) is pushed below the fold and rendered at half width.
- Present regardless of whether the product has 1 image or N images — the empty `#productThumbs` div still occupies a grid cell because `<div>` with `display: flex` counts as a grid item even when empty.
- Mobile (≤ 768px) is unaffected because the CSS collapses to `grid-template-columns: 1fr` and stacking is the intent there.
- User-visible on the primary revenue-generating surface of the site. This is the highest-severity finding of the run.

**Confidence:** High. Verified by reading:
- `product.html` line 106–108: `.product-detail.loaded { display: grid; grid-template-columns: 1fr 1fr; }`
- `product.html` lines 766–768: three direct children (`#productImage`, `#productThumbs`, `.product-detail-info`) inside `#productDetail`.
- CSS Grid auto-flow places children left-to-right, wrapping to a new row when the column count is exhausted. Three items in a 2-column grid → item 3 wraps to row 2 col 1.

**Suggested fix (smallest patch):** Wrap `#productImage` and `#productThumbs` in a single grid-cell container so they count as one grid child:

```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-image-wrap">
    <div class="product-detail-image" id="productImage"></div>
    <div class="product-detail-thumbs" id="productThumbs"></div>
  </div>
  <div class="product-detail-info">
    ...
  </div>
</div>
```

Alternative one-liner (CSS-only): give `#productThumbs` `grid-column: 1;` and move it after `.product-detail-info` in DOM order — but the wrapper is cleaner and matches the intended visual grouping.
