## Summary

Visual/UX hunt across the newer public pages (`shop.html`, `product.html`, `coaches.html`, `set-password.html`) plus a quick accessibility sweep of images and viewport metas across the site. One real regression on the product detail page: a recent gallery-thumbnails commit made the desktop layout drop the title, price, and Add-to-Cart button underneath the main image instead of beside it.

## Findings

### [P1] Product detail page layout broken on desktop — title/price/CTA get pushed below the image

**File:** `product.html:765-780` (HTML) and `product.html:100-108` (CSS)
**Category:** visual
**Status:** new — introduced by commit `f5cb8c4` ("feat: add image gallery with thumbnails on product page")

**What:** The product detail container is a 2-column CSS grid but now has three direct children (`#productImage`, `#productThumbs`, `.product-detail-info`). CSS grid auto-flows them into row 1 col 1, row 1 col 2, row 2 col 1 — so the thumbnail strip takes the right-hand column that the product title/price/Add-to-Cart was supposed to occupy, and `.product-detail-info` (title, price, CTA, description) drops to a second row below the main image.

**Why it matters:** `/product?p=...` is the primary conversion page for the shop. On desktop (`min-width: 769px`) the Add-to-Cart button is now far below the fold and visually disconnected from the product it belongs to, while the empty thumbnail strip occupies the prime real estate next to the image. Mobile (`max-width: 768px`) is unaffected because the grid collapses to a single column and the natural DOM order happens to be correct there, which is likely why this slipped through.

**Repro / evidence:**
1. Open `/product?p=<any-product-handle>` on a viewport >= 769px.
2. Observe layout: left column shows the main image; right column shows the thumbnails strip (even when there's only a single image, the empty `<div class="product-detail-thumbs">` still consumes the column because `display: flex` is unconditional at `product.html:120-124`).
3. The product info (`<div class="product-detail-info">` at `product.html:768`) lands on row 2 beneath the main image.

Relevant HTML (lines 765-768):
```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-image" id="productImage"></div>
  <div class="product-detail-thumbs" id="productThumbs"></div>
  <div class="product-detail-info">
    ...
```

Relevant CSS (lines 105-108):
```css
.product-detail.loaded {
  display: grid;
  grid-template-columns: 1fr 1fr;
}
```

The pre-regression version (before `f5cb8c4`) had only two children, which is what the 2-column grid expects.

**Suggested fix:** Nest the thumbnails inside the image column so the grid still has exactly two children. Either wrap `#productImage` and `#productThumbs` in a single `<div class="product-detail-media">` in the markup, or move the thumbs element to sit after the Add-to-Cart button inside `.product-detail-info` (gallery stays grouped with the main image is the cleaner read). Alternately, keep the three siblings but use `grid-template-areas` to pin `#productThumbs` under the image.
