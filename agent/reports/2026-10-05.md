### [P1] Product detail page: thumbnail gallery breaks the two-column grid layout
- **ID**: 2026-10-05-01
- **File(s)**: `product.html:765-779`, with CSS at `product.html:100-115` and `product.html:120-146`; JS populator at `js/shop.js:160-174`
- **Introduced in**: commit `f5cb8c4` ("feat: add image gallery with thumbnails on product page")
- **Reproduce**:
  1. Visit `product?p=<handle>` on desktop (>=769px wide).
  2. Inspect the `#productDetail` container. Its CSS is `display: grid; grid-template-columns: 1fr 1fr` (see `.product-detail.loaded`).
  3. It has three direct children in this order:
     - `<div class="product-detail-image" id="productImage">`
     - `<div class="product-detail-thumbs" id="productThumbs">`
     - `<div class="product-detail-info">`
  4. The grid places child 1 at (row 1, col 1), child 2 at (row 1, col 2), child 3 at (row 2, col 1). Result: thumbs appear where the title/price/add-to-cart column should be, and the entire product info block falls below the image in column 1, with column 2 empty under the thumbs.
  5. On a product with only 1 image, `shop.js:168` skips populating thumbs, so the thumbs cell is empty but still consumes col 2 of row 1 - right half of the page stays blank.
- **Impact**: Every product detail view on desktop is visually broken. The add-to-cart CTA is pushed below the image, cramped into half-width, and the right half of the page is empty or filled with just the thumbnail strip. This is the primary conversion surface for the new shop.
- **Suggested fix**: Wrap `.product-detail-image` and `.product-detail-thumbs` in a single parent column so the grid sees two children, not three. For example:
  ```html
  <div class="product-detail" id="productDetail">
    <div class="product-detail-media">
      <div class="product-detail-image" id="productImage"></div>
      <div class="product-detail-thumbs" id="productThumbs"></div>
    </div>
    <div class="product-detail-info"> ... </div>
  </div>
  ```
  Alternative one-liner: add `grid-column: 1 / -1` to `.product-detail-thumbs` so it spans both columns under the image, and give `.product-detail-info` an explicit `grid-column: 2; grid-row: 1 / span 2;`. The wrapper is cleaner.
- **Confidence**: High. The CSS, HTML, and the commit that introduced the regression are all in-tree; no runtime check needed.
