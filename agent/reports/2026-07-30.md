## BUG-2026-07-30-01 - Product detail page grid layout broken on desktop

- **severity:** P1
- **area:** Shop / product detail page (`/product?p=<handle>`)
- **file:** `product.html:100-115` (CSS) and `product.html:765-780` (HTML)
- **decision:** pending

### Repro
1. Visit any product detail URL, e.g. `https://www.telosathleticclub.com/product?p=<any-product-handle>`, on a viewport wider than 768px.
2. Wait for the Shopify product to load (spinner clears, `.product-detail` gets the `.loaded` class).

### Evidence
The grid parent is `.product-detail.loaded` with `grid-template-columns: 1fr 1fr` (two columns). But the parent has **three** direct children:

```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-image" id="productImage"></div>
  <div class="product-detail-thumbs" id="productThumbs"></div>
  <div class="product-detail-info">...</div>
</div>
```

CSS Grid auto-flows these three items into a 2-col grid as:

| | col 1 | col 2 |
|---|---|---|
| row 1 | image | **thumbs** |
| row 2 | **info** | (empty) |

Consequences on desktop:
- The thumbnail strip lands **in the right-hand column** (where the product info should be), on the same row as the main image.
- The product info block (title, price, add-to-cart, description) is **pushed to a new row below the image**, occupying the left column.
- The right half of row 2 is empty whitespace.

The intent (per the CSS: `.product-detail-thumbs { margin-top: 12px; }`) was clearly for thumbs to sit **under** the main image in the left column, with info in the right column.

This affects every multi-image product added after the image-gallery feature landed in commit `f5cb8c4` ("feat: add image gallery with thumbnails on product page"). Even single-image products render an empty `.product-detail-thumbs` div, so the grid remains a 3-cell layout with the same misplacement (though the misplaced cell is invisible when empty, info is still bumped down a row).

On mobile (`max-width: 768px`), the grid collapses to `1fr`, so all three children stack correctly - the bug is desktop-only.

### Fix
Wrap the image and thumbs in a single container so the grid receives exactly two children. Suggested edit in `product.html` around line 765:

```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-media">
    <div class="product-detail-image" id="productImage"></div>
    <div class="product-detail-thumbs" id="productThumbs"></div>
  </div>
  <div class="product-detail-info">
    ...
  </div>
</div>
```

No new CSS is required for `.product-detail-media` - it can be a plain block container, and existing `.product-detail-thumbs { margin-top: 12px; }` continues to position it correctly under the image.
