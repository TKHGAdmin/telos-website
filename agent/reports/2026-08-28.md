## Bugs

### BUG-2026-08-28-01  Product detail page layout broken on desktop by thumbnail markup

- **Severity**: P1
- **Focus**: functional
- **File(s)**: product.html
- **Introduced by**: f5cb8c4 ("feat: add image gallery with thumbnails on product page")

**What's wrong**
The thumbnails container was added as a direct sibling of the product image
and product info panels inside a two-column CSS grid, so grid auto-placement
puts the thumbs where the info panel is supposed to be. On desktop, every
product page renders as: image + thumbs strip in row 1, then the title /
price / add-to-cart / description stacked in the bottom-left of row 2 —
instead of image (with thumbs beneath) beside the info panel.

**Repro / evidence**
- `product.html:105-108` sets the container to
  `display: grid; grid-template-columns: 1fr 1fr;`.
- `product.html:765-780` places three siblings inside `#productDetail`:
  `#productImage`, `#productThumbs`, and `.product-detail-info`.
- With 3 children and 2 columns, grid auto-placement fills row 1 (image,
  thumbs) then wraps info to row 2 col 1. `.product-detail-thumbs` at
  `product.html:120-124` has `margin-top: 12px`, confirming the intent was
  for it to sit *under* the image, not next to it.
- The mobile breakpoint `@media (max-width: 768px)` collapses to one column,
  so the phone layout stacks image → thumbs → info correctly and hides the
  regression from mobile testing.

**Impact**
Every product detail page on desktop / tablet (≥769px) shows the info panel
below the image instead of beside it. Add-to-cart still works, but the page
looks broken and the fold above the CTA is wasted. Affects every shopper
who clicks a product card.

**Suggested fix**
Wrap `#productImage` and `#productThumbs` in a single column div so the grid
sees two children instead of three. No CSS change needed — the existing
`.product-detail-thumbs` styling already assumes it sits beneath the image.
