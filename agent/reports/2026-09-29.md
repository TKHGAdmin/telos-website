## P1 - Product detail page layout broken: `.product-detail-thumbs` breaks the two-column grid

**Area:** `product.html` / shop UX
**Introduced:** commit `f5cb8c4` ("feat: add image gallery with thumbnails on product page")
**Impact:** Every product detail page (`/product?p=<handle>`) - the primary shop conversion surface - renders with a broken layout on desktop. Product info (title, price, Add-to-Cart) drops below the image instead of appearing to its right.

### Evidence

`product.html:765-780` (the grid container and its children):

```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-image" id="productImage"></div>
  <div class="product-detail-thumbs" id="productThumbs"></div>   <!-- added in f5cb8c4 -->
  <div class="product-detail-info">
    <span class="product-detail-type" id="productType"></span>
    <h1 class="product-detail-title" id="productTitle"></h1>
    ...
  </div>
</div>
```

`product.html:105-115` (grid definition - unchanged from before the commit):

```css
.product-detail.loaded {
  display: grid;
  grid-template-columns: 1fr 1fr;
}

@media (max-width: 768px) {
  .product-detail.loaded {
    grid-template-columns: 1fr;
  }
}
```

The container is a 2-column grid but now has 3 direct children. With default `grid-auto-flow: row`, the third child wraps to a new row:

| | col 1 | col 2 |
|---|---|---|
| row 1 | `.product-detail-image` | `.product-detail-thumbs` (0-height when 0-1 images, or a strip of thumbs when 2+) |
| row 2 | `.product-detail-info` (all the sales copy + CTA) | empty |

The `.product-detail-thumbs` div is populated by `js/shop.js:168-174` only when `allImages.length > 1`, but the div itself is unconditionally in the DOM, so it always claims a grid cell.

### Repro

1. `npx serve -l 3000 .`
2. Visit `http://localhost:3000/shop`, click any product.
3. On desktop widths (>768px) observe: the product image fills the left column, right column above the fold is empty (or shows a strip of thumbnails), and the title / price / Add to Cart / description all appear in the LEFT column below the image.
4. Mobile is unaffected (`grid-template-columns: 1fr` at ≤768px).

### Suggested fix

Wrap the image + thumbs in a single grid cell. Either:

**Option A - HTML wrapper (smallest change):**

```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-media">
    <div class="product-detail-image" id="productImage"></div>
    <div class="product-detail-thumbs" id="productThumbs"></div>
  </div>
  <div class="product-detail-info">
    ...
  </div>
</div>
```

**Option B - CSS grid span (no HTML change):**

```css
.product-detail.loaded > #productImage  { grid-column: 1; grid-row: 1; }
.product-detail.loaded > #productThumbs { grid-column: 1; grid-row: 2; }
.product-detail.loaded > .product-detail-info { grid-column: 2; grid-row: 1 / span 2; }
```

Option A is preferable - it also lets thumbs be hidden cleanly when empty (`.product-detail-thumbs:empty { display: none }`), which fixes the incidental blank margin under the image on single-image products.
