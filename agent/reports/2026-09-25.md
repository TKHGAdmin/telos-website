## BUG-20260925-1 — P1 — Product detail grid layout broken on desktop after thumbs added

**Files:** `product.html:100-115`, `product.html:764-780`, `js/shop.js:161-174`

**Summary:**
The recent image-gallery commit (`f5cb8c4`) inserted `<div class="product-detail-thumbs">` as a third child of `<div class="product-detail">`, but that container is a two-column CSS grid (`grid-template-columns: 1fr 1fr`). The thumbnails now fill grid cell (row 1, col 2), pushing the product info block (title, price, Add to Cart, description) into (row 2, col 1) underneath the image. Only the desktop layout is affected — the `@media (max-width: 768px)` rule collapses to a single column, so mobile still stacks correctly.

**Reproduction / evidence:**
1. Open any product page in a viewport ≥ 769px: `https://www.telosathleticclub.com/product?p=<handle>` for a product with 2+ images.
2. Expected: image on the left column, product title/price/Add-to-Cart/description on the right column, thumbs strip under the image.
3. Actual: thumbs strip sits in the top-right where the info column should be; the entire info block drops to a second row beneath the image, and the right side of row 2 is empty whitespace.

The bug reproduces even for products with 0 or 1 images, because the `<div id="productThumbs">` element is always present in the DOM (only its innerHTML is skipped) and an empty flex box still occupies a grid cell.

Root cause in the CSS at `product.html:100-108`:
```css
.product-detail.loaded {
  display: grid;
  grid-template-columns: 1fr 1fr;
}
```
The template assumed exactly two children (image, info). The `product.html:766-767` change added a third:
```html
<div class="product-detail-image" id="productImage"></div>
<div class="product-detail-thumbs" id="productThumbs"></div>   <!-- new sibling -->
<div class="product-detail-info"> ... </div>
```
The thumbs container also has `margin-top: 12px` (`product.html:120-124`), which is only meaningful if it sits under the image in the same column — further evidence the author expected it to stack, not to occupy its own grid cell.

**Impact:**
Every desktop visitor to any `/product?p=…` page sees a broken layout: Add-to-Cart button and description live below the fold on a viewport where they should be right of the image. This is the conversion surface for the shop, so the impact is direct revenue and trust. Mobile is unaffected.

**Suggested fix:**
Smallest correct change is to wrap the image and thumbs in a single grid child, so the grid still sees two columns:
```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-media">
    <div class="product-detail-image" id="productImage"></div>
    <div class="product-detail-thumbs" id="productThumbs"></div>
  </div>
  <div class="product-detail-info"> ... </div>
</div>
```
No CSS grid changes needed; `.product-detail-thumbs { margin-top: 12px }` already positions the thumbs under the image inside the wrapper. Alternatively, keep the flat DOM and set `grid-column: 1` on `.product-detail-image` / `.product-detail-thumbs` and `grid-column: 2; grid-row: 1 / span 2` on `.product-detail-info` — more invasive.

**Confidence:** high
