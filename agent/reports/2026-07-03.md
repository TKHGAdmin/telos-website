## BUG-2026-07-03-001

**Severity:** P1
**Area:** product detail page (`/product`)
**File(s):** product.html:105-108, product.html:765-768

### Summary
The product detail page has a broken desktop layout: title, price, Add to Cart,
and description all sit under the main image in the left column, with the right
column empty. Only mobile (<=768px) renders correctly.

### Reproduce
1. Deploy the current `claude/ecstatic-gauss-5cj1ir` branch (or open
   `product.html?p=<any-shopify-handle>` in a viewport wider than 768px).
2. Expected: product image on the left, title/price/Add to Cart/description on
   the right (as it was before the May 20 image-gallery commit).
3. Actual: the info block wraps under the image on the left; the right column
   above the fold contains only the (optional) thumbnail strip - and is
   completely empty when the product has a single image.

### Root cause
Commit `f5cb8c4 feat: add image gallery with thumbnails on product page`
inserted `<div class="product-detail-thumbs" id="productThumbs">` as a third
direct child of `.product-detail`, but that container is
`display: grid; grid-template-columns: 1fr 1fr;` with no
`grid-template-areas` or explicit `grid-column` on the new element. Grid
auto-flow places three children as:

- `#productImage` -> row 1, col 1
- `#productThumbs` -> row 1, col 2 (was meant to sit under the image)
- `.product-detail-info` -> row 2, col 1 (was meant to be row 1, col 2)

The thumbs container's own `margin-top: 12px` and `display: flex` presume it is
stacked below the image, not placed alongside it. The mobile media query
collapses to `grid-template-columns: 1fr`, which hides the regression on small
screens - which is likely why this shipped.

### Suggested fix
Wrap the image and thumbnails in a single column, so `.product-detail` still
has two grid children:

```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-media">
    <div class="product-detail-image" id="productImage"></div>
    <div class="product-detail-thumbs" id="productThumbs"></div>
  </div>
  <div class="product-detail-info">...</div>
</div>
```

No CSS change needed beyond that (the existing `.product-detail-thumbs`
`margin-top: 12px` then does its job). Alternative one-liner if a DOM change
is undesirable: give the info block `grid-column: 2; grid-row: 1 / span 2;`
and the thumbs `grid-column: 1;` in the desktop rule.
