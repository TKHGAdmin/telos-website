That gives the grid three direct children in a `1fr 1fr` layout, so the thumbs land in the second column of row 1 (where the info block should be), and the info block wraps down to row 2 column 1 under the image. ## Bugs

### [P1] BUG-20260808-01 — Product detail page: thumbnails div breaks two-column grid layout

**File(s):** `product.html:100-108`, `product.html:765-780`, `js/shop.js:161-177`
**Category:** functional
**Introduced by:** f5cb8c4 ("feat: add image gallery with thumbnails on product page")

**What's wrong**
`.product-detail.loaded` is `display: grid; grid-template-columns: 1fr 1fr;`. It has three direct children in the DOM: `#productImage`, `#productThumbs`, and `.product-detail-info`. CSS Grid places them across two columns as:
- Row 1: `#productImage` | `#productThumbs`
- Row 2: `.product-detail-info` | (empty)

The thumbs strip was clearly meant to sit *underneath* the main image on the left (its own CSS uses `margin-top: 12px`, implying stacking under the image). Instead it sits **beside** the image, and pushes the entire product info block (title, price, add-to-cart, description) below the image on the left side of the page, leaving the right column blank.

**Failure scenario**
1. Deploy the site and open any product from `/shop` (e.g. `/product?p=<any-handle>`).
2. On a viewport wider than 768px, observe: main image top-left, empty (or thumbnail-only) space top-right, and title/price/Add-to-Cart/description stacked below the image on the left. The right half of the page is blank.
3. This happens for every product, including single-image products — the empty `<div id="productThumbs">` still occupies a grid cell because it's a direct child of the grid container.
4. On mobile (`max-width: 768px`), the grid collapses to a single column, so the visible symptom is a large empty gap between the image and the info block where the thumbs strip lives.

**Suggested fix**
Wrap the image and thumbs together so the grid sees only two children. In `product.html` around line 765, replace:
```
<div class="product-detail-image" id="productImage"></div>
<div class="product-detail-thumbs" id="productThumbs"></div>
<div class="product-detail-info">…</div>
```
with:
```
<div class="product-detail-media">
  <div class="product-detail-image" id="productImage"></div>
  <div class="product-detail-thumbs" id="productThumbs"></div>
</div>
<div class="product-detail-info">…</div>
```
No JS change needed — the existing selectors in `js/shop.js` still hit `#productImage` and `#productThumbs`. Alternatively, keep the DOM but tell grid to lay it out with `grid-template-areas` (`"image info" "thumbs info"`), which avoids the wrapper but is more brittle.
