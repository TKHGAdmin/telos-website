## Bug B-20260613-1 — Product detail grid has 3 children but only 2 columns, displacing product info below the image

- **Severity**: P1
- **Area**: product.html (template + inline CSS)
- **Confidence**: high
- **Status**: new

### Evidence

`product.html:105-108` declares a two-column grid for the loaded state:

```css
.product-detail.loaded {
  display: grid;
  grid-template-columns: 1fr 1fr;
}
```

`product.html:765-780` places three direct grid children inside `.product-detail` — `.product-detail-image`, `.product-detail-thumbs`, and `.product-detail-info`:

```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-image" id="productImage"></div>
  <div class="product-detail-thumbs" id="productThumbs"></div>
  <div class="product-detail-info">
    <span class="product-detail-type" id="productType"></span>
    <h1 class="product-detail-title" id="productTitle"></h1>
    <div class="product-detail-price" id="productPrice"></div>
    <button class="btn-add-cart-lg" id="productAddBtn"> ... </button>
    ...
  </div>
</div>
```

With CSS Grid auto-placement and only two columns, the three children fill cells in this order:
- Row 1, Col 1: `.product-detail-image`
- Row 1, Col 2: `.product-detail-thumbs` (the thumbnail strip ends up where the title/price/CTA should be)
- Row 2, Col 1: `.product-detail-info` (title, price, and Add to Cart button pushed under the image)

`.product-detail-thumbs` (`product.html:120-124`) has no grid positioning rules, only `display: flex; gap: 10px; margin-top: 12px`, so it still occupies its auto-placed cell even when JS leaves it empty (`js/shop.js:168` only fills the strip when `allImages.length > 1`).

### Reproduction

1. Open the shop on desktop (>=769px viewport).
2. Click any product card to navigate to `/product?handle=...`.
3. Observe: the large image fills column 1; column 2 of row 1 is either an empty cell (single-image products) or a row of small thumbnails (multi-image products). The product title, price, and "Add to Cart" button render in row 2, column 1, beneath the image, instead of next to it.
4. Switching to a viewport `<=768px` masks the bug because the media query at `product.html:110-115` collapses the grid to a single column.

### Impact

Every shop visitor on desktop and tablet lands on a product page where the headline, price, and primary CTA are below the fold — they have to scroll past a large hero image to find what they are buying or how to buy it. The most important conversion element on the page (the Add to Cart button) is the hardest to find. Mobile is unaffected.

### Suggested fix

Make the left column a single grid child by wrapping the image and thumbnail strip in one container (so the grid has exactly two children: media stack and info), or alternatively pin the thumbs strip to column 1 via grid placement so the info stays in column 2 of row 1.
