## P1 — Product detail page layout breaks: info panel wraps under image

**File**: `product.html`
**Lines**: `100-108` (CSS) and `765-780` (HTML markup)
**Introduced by**: commit `f5cb8c4` ("feat: add image gallery with thumbnails on product page", 2026-05-20)

### What is wrong

`.product-detail.loaded` is a 2-column grid:

```css
.product-detail.loaded {
  display: grid;
  grid-template-columns: 1fr 1fr;
}
```

But the HTML now has **three** direct grid children:

```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-image"  id="productImage"></div>
  <div class="product-detail-thumbs" id="productThumbs"></div>   <!-- new in f5cb8c4 -->
  <div class="product-detail-info">...</div>
</div>
```

With 3 children and 2 columns the auto-placement algorithm lays them out:

- Row 1, Col 1 — image
- Row 1, Col 2 — thumbs
- Row 2, Col 1 — info (title, price, add-to-cart, description)
- Row 2, Col 2 — empty

That is not the intended layout. The thumbnail strip was meant to sit **below** the main image (its own CSS at `product.html:120-124` gives it `display:flex; gap:10px; margin-top:12px;` — clearly designed as a strip under the image, not as a peer column).

Impact: every product detail page on desktop renders with the title/price/description column pushed under the image at half-width and half of row 2 blank — visually broken, and it happens even for single-image products because `#productThumbs` is always in the DOM and still occupies a grid cell even when empty. It affects every visitor who lands on `/product?p=<handle>`.

### Reproduce

1. Visit `https://www.telosathleticclub.com/product?p=<any-handle>` on desktop (>768px wide, where the mobile 1-column fallback does not kick in).
2. Observe the product image on the left. Instead of title + price + description + add-to-cart to its right, that column is empty (or holds the empty thumbs strip when the product has multiple images), and the info block appears in a second row under the image.

### Suggested fix

Move `#productThumbs` inside the image column so the grid stays 2-child, e.g.:

```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-image-wrap">
    <div class="product-detail-image"  id="productImage"></div>
    <div class="product-detail-thumbs" id="productThumbs"></div>
  </div>
  <div class="product-detail-info">...</div>
</div>
```

Or, less surgical, change the grid to `grid-template-columns: 1fr 1fr` + `grid-template-areas` and pin the thumbs under the image via `grid-area`. The wrap-div approach is smaller and keeps the existing thumbs CSS working as-is.

### Confidence

High. The bug is a direct consequence of the diff — a third grid child added to a 2-col grid with no accompanying grid-area / span rule. No JS conditional hides the thumbs element when there is one image (the JS only skips *populating* it, so the empty div still occupies the second cell).
