## Findings

### 20260815-01 — Product detail page grid wraps info block below image

- **Severity:** P1
- **File(s):** `product.html:765-780`, `product.html:105-108`
- **Category:** functional
- **Confidence:** high

**What is wrong**

`.product-detail.loaded` is a two-column grid
(`grid-template-columns: 1fr 1fr`, `product.html:105-108`) but the
`#productDetail` container now has three direct children:
`.product-detail-image`, `.product-detail-thumbs`, and
`.product-detail-info` (`product.html:765-780`). CSS Grid places the
first two children into the top row (image left, an almost-empty thumb
strip right) and wraps `.product-detail-info` onto a second row in the
left column. The right column becomes empty and the product title,
price, add-to-cart button, and description all appear below the image
instead of beside it. The bug ships to production for every product,
whether the product has one image (thumbs div is empty but still
occupies a grid cell) or several (thumbs render inside the info
column).

The regression landed in commit `f5cb8c4` ("feat: add image gallery with
thumbnails on product page") which inserted `.product-detail-thumbs` as
a sibling of `.product-detail-image` without changing the grid to two
rows or wrapping the image + thumbs in a container.

**Why it matters**

Every visitor who clicks a product card lands on a broken detail page:
the buy button and the description are pushed below a 560px-tall image
and disappear below the fold on 1080p laptops. On desktop the right
half of the viewport is mostly whitespace with a floating 72px thumbnail
strip. This directly hurts conversion on the shop that was just wired
up.

**Reproduction / evidence**

1. Local dev: `npx serve -l 3000 .` then open
   `http://localhost:3000/product?p=<any-handle>` for any product with
   at least one image.
2. Observe the rendered grid: `#productImage` in row 1 column 1,
   `#productThumbs` in row 1 column 2, `.product-detail-info` in row 2
   column 1.
3. DevTools → Elements → `#productDetail` shows three flex/grid
   children where the CSS expects two.

Grid layout math:

```
grid-template-columns: 1fr 1fr;   /* 2 columns */
children: image, thumbs, info;    /* 3 items → 2 rows */

row1: [ image ] [ thumbs (mostly empty) ]
row2: [ info  ] [ empty                 ]
```

**Suggested fix**

Wrap the image and thumbs in a single container so the grid sees two
children:

```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-media">
    <div class="product-detail-image" id="productImage"></div>
    <div class="product-detail-thumbs" id="productThumbs"></div>
  </div>
  <div class="product-detail-info">
    ...
  </div>
</div>
```

No CSS change required beyond an optional
`.product-detail-media { display: flex; flex-direction: column; }` for
tidy stacking. Alternative fix: change the grid to explicitly place
`.product-detail-info { grid-column: 2; grid-row: 1 / span 2; }` and
have thumbs sit under the image in column 1 — but the wrapper is
simpler and matches the JS assumption in `js/shop.js:161-174` that
image and thumbs live together.
