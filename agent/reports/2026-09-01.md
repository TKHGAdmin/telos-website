# Bug Report 2026-09-01

**Focus:** Functional
**Bugs found:** 2
**Summary:** Product-detail page layout is broken on every render (grid has 3 children but only 2 columns), and the cart drawer's empty-state message never appears for first-time visitors.

---

## BUG-2026-09-01-01 — [P1] Product detail page: info panel wraps under image on every product

**Severity:** P1
**Area:** product.html
**Anchor:** `product.html:105-108` (CSS) and `product.html:765-780` (HTML)

**What's wrong**
`.product-detail.loaded` declares a two-column grid, but the container has three grid children in this order: `#productImage`, `#productThumbs`, `.product-detail-info`. Because CSS Grid places items left-to-right, top-to-bottom, the info panel is auto-placed at (row 2, col 1) — i.e. directly *below* the product image instead of beside it. This affects every product on `/product?p=...`, not just multi-image ones: the empty `#productThumbs` div still occupies the (row 1, col 2) cell.

For products that DO have multiple images, `#productThumbs` is populated by `js/shop.js:169-173` and appears in the wrong slot — floating alongside the main image in the right column, where the info panel and Add-to-Cart button should be.

**Repro / evidence**
1. Deploy to any environment with a live Shopify catalog.
2. Visit `/product?p=<any-handle>`.
3. Observe layout: image on left, blank/thumbs on right, title / price / Add-to-Cart wraps to a second row on the left.

The relevant CSS (`product.html:100-108`):
```css
.product-detail {
  display: none;
  gap: var(--spacing-3xl);
}
.product-detail.loaded {
  display: grid;
  grid-template-columns: 1fr 1fr;
}
```

The relevant HTML (`product.html:765-780`):
```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-image" id="productImage"></div>
  <div class="product-detail-thumbs" id="productThumbs"></div>
  <div class="product-detail-info">
    ...
  </div>
</div>
```

The recent commit `f5cb8c4` ("feat: add image gallery with thumbnails on product page") added the `#productThumbs` sibling without adjusting either the grid or the DOM nesting.

**Proposed fix**
Wrap the image and thumbs in a single left-column div so the grid sees only two direct children:
```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-gallery">
    <div class="product-detail-image" id="productImage"></div>
    <div class="product-detail-thumbs" id="productThumbs"></div>
  </div>
  <div class="product-detail-info">...</div>
</div>
```
Or (simpler) span the info panel across `grid-row: 1 / span 2; grid-column: 2;` and let thumbs stack below image via `grid-column: 1;` on the thumbs element. Either fix restores the intended two-column layout.

## BUG-2026-09-01-02 — [P3] Cart drawer shows blank content (no empty-state) on first visit

**Severity:** P3
**Area:** js/shop.js
**Anchor:** `js/shop.js:77-81` (see also `product.html:727` / `shop.html` cart-drawer markup)

**What's wrong**
`createFreshCheckout()` creates a Shopify checkout and stores its id, but never calls `syncCartFromCheckout(checkout)`. That means neither `updateCartBadge()` nor `renderCartDrawer()` runs on a first-time visit (no `telos_checkout_id` in `localStorage`). The cart-drawer's items container (`#cartItems`) is initially empty HTML with no "Your cart is empty" state — so if a new visitor clicks the cart icon before adding anything, the drawer slides open displaying blank space where the empty-state icon + copy should be. The empty-state HTML *is* implemented in `renderCartDrawer()` at `js/shop.js:410-417`; it just never fires until after the first `addToCart` mutation.

**Repro / evidence**
1. Clear site data / open a fresh incognito window.
2. Navigate to `/shop` or `/product?p=<handle>`.
3. Without adding anything, click the cart icon in the top nav.
4. Observed: drawer slides in with title "Cart" and an empty body — no icon, no "Your cart is empty" copy.
5. Expected (per `js/shop.js:408-417`): the drawer should show the empty cart illustration and "Your cart is empty / Browse the shop to add items".

**Proposed fix**
In `createFreshCheckout()`, call `syncCartFromCheckout(checkout)` after storing the id — the checkout object already carries `lineItems: []`, `subtotalPrice`, and `webUrl`, so a single line resolves it:
```js
async function createFreshCheckout() {
  const checkout = await shopifyClient.checkout.create();
  checkoutId = checkout.id;
  localStorage.setItem('telos_checkout_id', checkoutId);
  syncCartFromCheckout(checkout);
}
```
