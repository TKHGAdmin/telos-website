## BUG-2026-06-18-01 — Product page thumbnails land in the wrong grid cell on desktop

- **Severity:** P1
- **Area:** Shop / product detail page
- **Files:** `product.html` (lines 100–115, 765–779), `js/shop.js` (lines 160–177)
- **Introduced in:** commit `f5cb8c4` — "feat: add image gallery with thumbnails on product page" (2026-05-20)
- **Status:** New, shipped to production

### What's wrong

`.product-detail` is a two-column grid (`grid-template-columns: 1fr 1fr`), but
`product.html` puts **three** direct children inside it: image, thumbs, and
info.

```html
<div class="product-detail" id="productDetail">
  <div class="product-detail-image"  id="productImage"></div>   <!-- row 1, col 1 -->
  <div class="product-detail-thumbs" id="productThumbs"></div>  <!-- row 1, col 2  ⟵ wrong cell -->
  <div class="product-detail-info">                              <!-- row 2, col 1 -->
    ...
  </div>
</div>
```

```css
.product-detail.loaded {
  display: grid;
  grid-template-columns: 1fr 1fr;
}
```

On desktop, the thumbnails render **to the right of the main image**, in the
cell intended for the title/price/add-to-cart. The info block then drops to
row 2 under the image, and the right half of row 2 sits empty. The intended
layout (thumbs as a horizontal strip beneath the main image) only renders
correctly when the product has a single image — because in that case the
JS in `shop.js:168–174` never populates `#productThumbs`, leaving it as a
zero-height empty grid item.

The thumb CSS (`display: flex; margin-top: 12px;`) confirms the intent: a
row of thumbnails below the hero image, not a sibling of the info column.

### Reproduction

1. Open `/product?p=<any-handle-with-2+-images>` on a viewport > 768px wide.
2. Observe: thumbnail strip appears in the right column where the product
   title, price, and Add-to-Cart should live.
3. The info block (title, price, button, description) renders below the
   image instead of beside it.

Single-image products mask the bug because `productThumbs` stays empty.

### Evidence

- `product.html:765-779` — three direct grid children
- `product.html:105-108` — 2-column grid declaration
- `product.html:120-124` — thumbs styled as a horizontal flex row (intent)
- `js/shop.js:168-174` — thumbs only injected when `allImages.length > 1`
- Git: `git show f5cb8c4 -- product.html` shows `#productThumbs` was added
  as a sibling of `.product-detail-info` inside the existing grid

### Recommended fix

Move `#productThumbs` **inside** the image column so the grid stays 2×1.
Either wrap image+thumbs in a single container, or place thumbs inside
`.product-detail-info` above the title. Smallest diff:

```html
<div class="product-detail" id="productDetail">
  <div>
    <div class="product-detail-image"  id="productImage"></div>
    <div class="product-detail-thumbs" id="productThumbs"></div>
  </div>
  <div class="product-detail-info"> ... </div>
</div>
```

No JS change needed.

### Impact

Anyone visiting a multi-image product on desktop sees a broken layout —
title and Add-to-Cart pushed below the fold, thumbnails sitting where the
buy button should be. This is on the primary commerce path; users who
manage to scroll can still purchase, but conversion will drop and the
page looks shipped-broken.
