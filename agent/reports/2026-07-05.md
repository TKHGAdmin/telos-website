## Findings

### [P1] Product-detail page layout is broken — thumbnails render where product info should

- **File:** `product.html:765`
- **Category:** layout / regression
- **What's wrong:** `.product-detail.loaded` is a two-column CSS grid (`grid-template-columns: 1fr 1fr;`, defined at `product.html:107`). Its immediate children determine grid cell placement. Commit `f5cb8c4` ("feat: add image gallery with thumbnails on product page") inserted a third direct child between the image and the info block:

  ```html
  <div class="product-detail" id="productDetail">
    <div class="product-detail-image" id="productImage"></div>
    <div class="product-detail-thumbs" id="productThumbs"></div>  <!-- new -->
    <div class="product-detail-info">…</div>
  </div>
  ```

  With three children in a two-column grid, layout collapses to:

  ```
  row 1: [image]      [thumbs]
  row 2: [info]       [empty]
  ```

  So on every product-detail page, the thumbnails render in the right-hand column where the title / price / add-to-cart / description should live, and the info block gets pushed down to the second row occupying only the left column. This isn't a "sometimes on mobile" glitch — it fires for every product regardless of image count, because the thumbs `<div>` is always in the DOM (see `js/shop.js:162`, populated only when >1 image, but the container element itself is always present).

- **How to reproduce:**
  1. `npx serve -l 3000 .` (or hit prod).
  2. Navigate to `/shop`, click any product tile.
  3. Product-detail view loads; observe that the "PRODUCT TYPE / Title / Price / Add to Cart / Description" column is sitting under the image instead of beside it, and the thumbnail strip (empty when a product has ≤1 image) is occupying the right-hand column.

- **Failure scenario:** A user clicking a product on `/shop` lands on `/product?p=<handle>`. The image loads at ~560px on the left; the entire buy panel — title, price, Add-to-Cart button, description — is now below the image on the left, while the right half of the page is either empty or shows an unmoored strip of thumbnail chips. The Add-to-Cart button is much harder to spot and no longer next to the image, degrading conversion on the primary revenue surface.

- **Suggested fix:** Move `#productThumbs` inside `.product-detail-info` (or wrap image + thumbs in a single grid child). Minimal patch:

  ```diff
  <div class="product-detail" id="productDetail">
  -  <div class="product-detail-image" id="productImage"></div>
  -  <div class="product-detail-thumbs" id="productThumbs"></div>
  +  <div>
  +    <div class="product-detail-image" id="productImage"></div>
  +    <div class="product-detail-thumbs" id="productThumbs"></div>
  +  </div>
     <div class="product-detail-info">
  ```

  Or, if the thumbs should sit under the info column instead, move the `<div class="product-detail-thumbs">` to after the image but wrap image+thumbs in a single container `<div>` so the grid only ever sees two children. Additionally consider hiding `.product-detail-thumbs` when it's empty (`js/shop.js:168` only fills it when `allImages.length > 1`) to avoid the 12px top margin appearing under single-image products.
